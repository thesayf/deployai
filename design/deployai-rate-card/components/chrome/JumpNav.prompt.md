JumpNav is the sticky periwinkle in-page anchor band (uppercase tracked links) used on services/diagnostic pages — not on Home. An optional outline CTA fades in once the bar sticks.

```jsx
<JumpNav sections={[{ label: "What it is", anchor: "#what" }, { label: "Deliverables", anchor: "#deliver" }]} cta={{ label: "Let's talk", href: "#book" }} />
```
